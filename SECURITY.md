# Security

Security fixes are maintained on the current development line and included
in the next release. Use an up-to-date revision and supported dependencies.

For a security-sensitive problem, open a
[contact request](https://github.com/yeruciwenrou-dotcom/homological-observability/issues/new?template=security_contact.yml)
requesting a private reporting channel. Include the affected version and
component, and share exploit details or sensitive data only after a maintainer
has arranged that channel.

Numerical discrepancies, model-validation errors, and incorrect scientific
results belong in the ordinary bug-report form. Include a minimal example
and the mathematical expectation so the result can be checked independently.
